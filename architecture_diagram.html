Component Guide

Client Dashboard

Serves as the interactive dashboard UI to display monitoring feeds, trigger mock/GEE scans, and initiate chat streams.

FastAPI Service

Backend routing engine running REST endpoints and generating Server-Sent Events (SSE) chat streams for real-time agent output.

AI Agent & Tools

Powered by Gemini 1.5/3 Flash via Google ADK. Invokes custom tools for GEE image scanning and alert logging.

Storage & Fallback

Persistent storage via MongoDB Atlas, defaulting gracefully to local storage and Pillow image synthesis if keys are missing.

Observability

Tracks agent execution logic and tool responses via OpenTelemetry and Arize Phoenix.
